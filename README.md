# Subhasish & Ipshita — Wedding Website

Floral wedding invitation for **Subhasish & Ipshita**.

- Wedding: **26 January 2027** — Rajwada Banquet
- Reception: **28 January 2027** — Tirupati Balaji Banquet
- Theme: **Floral**

## Features
- Slow right-to-left auto-scrolling photo cards
- Touch-friendly gallery with temporary pause while swiping
- No gallery lightbox; photos are display-only
- Photo drag/right-click/double-click protection
- Four supplied couple photos
- Original parallax background
- Wedding countdown and music player
- Reception calendar button

## Music
Place `Khat.mp3` in the same folder as `index.html`.


## Gallery behavior
The gallery auto-scrolls slowly from right to left for one complete cycle, then freezes so visitors can manually scroll/swipe through the photographs.


## Responsive gallery
The photo gallery is optimized for both laptop/desktop and mobile:
- Desktop: slow one-cycle animation, then mouse-wheel or click-drag scrolling.
- Mobile: slow one-cycle animation, then native horizontal swipe scrolling.
- Tablet: intermediate card sizing and animation speed.
- Small screens: card widths adapt to the viewport.
